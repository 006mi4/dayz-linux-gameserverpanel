# Terminal texts of the DZPage Panel: install.sh, dzpage-panel, uninstall,
# HTTPS and the admin program. One line per text: key=text. Lines starting
# with # are comments. {name} is replaced when printed; keep every {name} of a
# line in the translation, change only the words around it. Commands, paths,
# options and words in quotes that the user has to type stay as they are.
# No leading or trailing spaces, no line breaks inside a text.
#
# English is the reference: every other file has exactly the same keys, and a
# key missing there falls back to the English text.
